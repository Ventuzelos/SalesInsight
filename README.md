# SalesInsight

Python project for exploring and analyzing sales data using Pandas, Matplotlib and Object-Oriented Programming.

## About the project

SalesInsight is a sales data analysis project developed as part of a final assignment for a Python course.

The project processes a CSV dataset containing sales records and extracts useful business insights, including sales volume, revenue, top-selling products and category performance.

The project also includes data cleaning and data visualization using Matplotlib.

## Objectives

The main objectives of the project are:

- Load and explore sales data using Pandas
- Identify and clean invalid sales records
- Calculate total revenue
- Identify the best-selling product
- Analyze the top 5 products by units sold
- Analyze revenue by product category
- Analyze sales evolution over time
- Create visualizations using Matplotlib
- Apply Object-Oriented Programming principles in Python
